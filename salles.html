Vous organisez un loto ?

Créez une salle gratuite pour diffuser le tirage sur les téléphones des joueurs. Pas de compte : la salle disparaît toute seule après quelques heures sans activité. Ici, la salle est fictive.

Salle fictive. Rien n’est créé sur un serveur et ce code ne fonctionne pas dans OpenLoto. Dans le vrai service, la clé de diffusion n’est affichée qu’une fois et la salle se retrouve depuis le même navigateur.

  1. Téléchargez OpenLoto si vous ne l’avez pas déjà : OpenLoto.html. Il s’ouvre sur votre ordinateur, sans installation.
  2. Branchez la salle. Dans OpenLoto, cliquez sur « Téléphones » en haut de l’écran, collez l’adresse et la clé, puis « Tester la connexion ».
  3. Invitez les joueurs. Donnez-leur le code ou le lien : ils suivent le tirage sans rien installer.

OpenLoto est gratuit et libre (licence MIT). Dans le futur service : aucune donnée personnelle conservée, les salles n’existent qu’en mémoire.
